## 🛠️ Stack Technique & Architecture

- **Frontend Core :** React 18, Vite
- **Styling :** Tailwind CSS, Glassmorphism, Thème sombre moderne
- **Icônes :** Lucide React
- **Déploiement :** Vercel CI/CD
- **Fonctionnalités :**
  - Filtrage interactif par catégorie (E-Commerce, Gaming, Social, Voyage, CRUD, Backend)
  - Modale d'inspection avec détails techniques pour chaque TP
  - Responsive Mobile / Tablette / Desktop

## 💻 Installation & Démarrage Local

```bash
# 1. Cloner le projet
git clone https://github.com/AyaBouzommita/portfolio-react.git
cd portfolio-react

# 2. Installer les dépendances
npm install

# 3. Lancer le serveur local
npm run dev

# 4. Compiler pour la production
npm run build
```

---

## 🌐 Déploiement sur Vercel

1. Connectez votre compte GitHub à [Vercel](https://vercel.com).
2. Cliquez sur **Add New Project** et sélectionnez **portfolio-react**.
3. Conservez les paramètres par défaut (Framework Preset: **Vite**).
4. Cliquez sur **Deploy** !
